Lessons Built Into This App

  • Status is context, not a task.
  • Fixed items and flex items need different treatment.
  • Flex items need a real decision: done or not done.
  • Daily support has to stay visible, small, and practical.
  • Runs and lifts need result logging, not just checkboxes.
  • Room days should show the actual room checklist.
  • FULL / MIN / RECOVERY prevents pass/fail tracking.
